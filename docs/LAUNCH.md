# 출시·수익화 가이드 — 요트 파라다이스 레이싱 (웹)

이 문서는 게임을 실제로 출시해 돈을 벌기까지 **남은 일**을 정리한다. 코드로 할 수 있는 일은 끝냈고, 아래 "사용자 계정이 필요한 일"은 운영자가 직접 해야 한다.

## 1. 수익 구조

| 수익원 | 어디서 | 상태 |
|---|---|---|
| 보상형 광고 | 레이스 결과 "상금 2배", 매일 접속 보상 "2배" — 플레이어가 원할 때만 | 코드 완료 (Poki·CrazyGames SDK 연결부) |
| 전면 광고 | 결과 → 파라다이스로 돌아갈 때, 처음 3판 이후 2판마다. 레이스 중에는 절대 없음 | 코드 완료 |
| 서포터 팩 (유료) | 전용 스킨 2종 + 전면 광고 제거 | 개발용 가짜 결제만. 실제 결제 연동은 아래 4절 |
| 스킨 상점 (게임 내 CR) | 돈이 쌓인 뒤의 목표 → 플레이 시간 증가 → 광고 노출 증가 | 완료 (5종 + 서포터 2종) |
| 재방문 | 매일 접속 보상(7일 주기), 일일 미션 3개 | 완료 |

광고 플랫폼 선택: 주소 뒤 `?platform=poki` / `?platform=crazygames`, 또는 배포 환경변수 `NEXT_PUBLIC_GAME_PLATFORM`. 설정이 없으면 배포본은 광고 없이(버튼 숨김) 동작한다. 코드: `components/boat/platform.ts`.

## 2. 출시 경로 (추천 순)

1. **CrazyGames** — 웹 게임 포털, 광고 수익 배분, 개발자 포털에서 직접 제출. 게임을 정적 파일(HTML/JS)로 올린다.
2. **Poki** — 심사가 까다롭지만 트래픽이 크다. Poki가 먼저 연락하거나 신청서로 제출.
3. **자체 도메인** (Vercel 등) — 광고는 AdSense for Games 등 별도 계약 필요. 결제(서포터 팩)를 직접 붙이기 가장 쉽다.

## 3. 운영자 계정이 필요한 일 (체크리스트)

- [ ] 포털 개발자 계정 만들기 (CrazyGames Developer Portal / Poki 신청)
- [~] 포털 SDK 검증 — 실제 SDK를 로드해 확인함(2026-11-06): Poki는 쓰는 함수 전부 실존, CrazyGames는 스크립트·init·data 모듈 확인. **남은 것**: CrazyGames `requestAd` 콜백 이름은 init 후에만 보이므로 포털 QA 도구에서 광고 1회 재생 확인
- [x] 정적 빌드 — `node scripts/build-portal.mjs crazygames|poki|none` 가 `dist-portal/yacht-paradise-<플랫폼>.zip`(index.html 한 파일, 약 2.8MB)을 만든다. 포털 개발자 포털에 그대로 업로드
- [ ] 썸네일·아이콘을 포털 규격으로 만들기 (`docs/boat-image-prompts.md`의 이미지 활용)
- [ ] 개인정보처리방침에 운영자 이름·연락처·시행일 채우기 (`app/boat/privacy/page.tsx`)
- [x] 영어 UI — 브라우저 언어가 ko가 아니면 영어로 표시 (`lib/boat/i18n.ts`). 남은 것: 개인정보처리방침 영어판
- [ ] 배포 주소를 `NEXT_PUBLIC_SITE_URL`에 넣기 (공유 미리보기 이미지 절대 주소)
- [ ] 서포터 팩 가격 정하기 + 결제 연동 (4절)

## 4. 서포터 팩 실제 결제

포털마다 다르다. 운영자 계정·심사가 필요해 코드만으로 끝낼 수 없다.
- CrazyGames: 플랫폼 결제(Xsolla) 연동을 제공한다 — 승인 필요, 확인 필요
- Poki: 게임 내 결제를 지원하지 않는 것으로 알고 있다 — 확인 필요. Poki판에서는 서포터 버튼이 "구매할 수 없어요"로 표시된다 (`purchaseAvailable: false`)
- 자체 도메인: Stripe·토스페이먼츠 등 결제 + 구매 확인 서버가 필요하다. 지금 저장은 브라우저(localStorage)에만 있어서, 결제 상태를 서버에서 확인하지 않으면 쉽게 조작될 수 있다

## 5. 정적 빌드

`node scripts/build-portal.mjs <crazygames|poki|none>` 한 줄로 끝난다. 이미지·음악까지 넣은 index.html 한 파일(4.3MB)과 업로드용 zip(2.8MB)이 `dist-portal/`에 생긴다. 광고 플랫폼은 빌드에 고정되고, `none`은 광고·결제 없는 자체 배포용이다. 포털 밖에서 열면 SDK init에 8초 제한이 걸려 자동으로 광고 없는 모드로 동작한다(스모크 테스트 확인).

## 6. 코드로 확인한 것 / 못 한 것

확인함: 단위 테스트(상점·접속 보상·미션·광고 빈도·저장 복구), 타입 검사, 린트, 프로덕션 빌드, 브라우저에서 접속 보상 2배 → 상점 → 레이스 → 상금 2배 → 서포터 구매 → 전용 스킨 레이스 흐름.

못 함 (확인 필요): 실제 포털 SDK 광고 재생, 실제 결제, 실기기(저사양 폰) 성능, 영어 사용자 반응, 장기 밸런스(실제 이용자 데이터).
