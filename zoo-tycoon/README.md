# 해바라기 동물원 (동물원 타이쿤)

빌드 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있는 단일 파일 게임입니다.

## 플레이 방법
### 화면 (가로 모드)
- 게임 화면이 가로로 화면 전체를 채웁니다. 동물원은 가운데에 놓이고, 잔디·길·나무가 화면 끝까지 이어집니다. 위: 돈·관람객·인기도·☰ 메뉴 / 왼쪽 아래: ▲◀▶▼ (터치 기기에서만) / 오른쪽 아래: 꾸미기·서커스, 아기 판다 감시 / 맨 아래: 지금 상태. 조작 버튼은 게임 화면 위에 떠 있고, 동물원은 버튼에 가리지 않는 크기로 맞춰집니다.
- 시작 화면의 **게임 시작**을 누르면 전체 화면 + 가로 고정을 시도합니다(브라우저가 허용할 때만).
- 화면이 세로이면 게임 화면 전체를 90° 돌려서 항상 가로로 보여줍니다. 휴대폰을 옆으로 돌려서 하면 됩니다.
- 하는 법, 동물 도감, 처음부터 다시 하기는 ☰ 메뉴 안에 있습니다(메뉴를 여는 동안 게임 멈춤).

키보드 방향키·WASD, 또는 화면 아래 ▲◀▶▼ 버튼(휴대폰용, 누르고 있는 동안 이동)으로 **사육사**를 움직입니다. 화면 터치로는 이동하지 않습니다(아기 판다 미니게임만 터치).

### 돌보기: 도구 챙기고 기다리기
길 가운데에 도구함 3개가 있습니다. 도구함 안에 1.2초 서 있으면 그 도구를 챙기고(한 번에 하나), 도구를 든 채 그 일이 필요한 우리 안에서 기다리면 진행 링이 차고 일이 끝납니다. 도구는 다른 도구함에서 바꿀 때까지 계속 들고 다닙니다.

| 도구함 | 우리에서 하는 일 | 걸리는 시간 | 언제 할 수 있나 |
|---|---|---|---|
| 🥕 먹이 창고 | 밥주기 (마리당 5원) | 2초 | 배부름 90 미만 |
| 🧹 청소도구함 | 청소 | 2.5초 | 청소 주기가 다 차서 똥이 생겼을 때. 5초 안에 치우면 +10원. 15초 넘게 두면 **냄새** → 관람객이 크게 줄고, 그 우리 앞 관람객은 🤢 하고 떠남 |
| 🌱 정원 도구함 | 가꾸기 | 2.5초 | 정원 85 미만. 정원 수치는 천천히 줄고, 낮아지면 잡초·시든 꽃이 보이고 행복도가 떨어짐 |

행복도 = 배부름 40% + 청결 40% + 정원 20%.

### 사기·키우기: 발판에 서 있기
발판에 1.5초 서 있으면 돈을 내고 진행됩니다. 같은 발판에서 또 하려면 발판에서 내려왔다가 다시 올라가야 합니다.

| 발판 | 위치 | 설명 |
|---|---|---|
| 🐾 동물 사기 | 빈 우리 아래쪽 | 우리마다 파는 동물이 정해져 있음 (위: 토끼·펭귄·원숭이·얼룩말 / 아래: 기린·사자·코끼리·판다). 사면 배달 상자가 오고 `6 + 가격/100`초 뒤 도착 |
| ⬆ 업그레이드 | 우리 아래 왼쪽 | Lv.1→3. 수용량 2→3→4마리, 청소 주기 30→38→46초, 인기도 +10%/단계 |
| ➕ 한 마리 | 우리 아래 오른쪽 | 수용량까지 같은 동물 추가 (인기도↑, 밥값↑) |

꾸미기·서커스는 우리 안에서 버튼(G)으로 합니다. 토끼·얼룩말·기린·판다는 꾸미기(꽃밭·장난감·예쁜 집, 각 인기도 +25%), 펭귄·원숭이·사자·코끼리는 서커스(배부르고 깨끗할 때, 10초 공연, 관람객이 몰려와 큰 팁, 45초 쿨타임).

- 관람객은 입장료 5원을 내고, 만족한 동물 앞에서 팁을 줍니다.
- **미니게임: 아기 판다 감시하기** — 30초 동안 ❗가 뜬 아기 판다를 눌러 울타리 안으로 데려옵니다.
  3번 놓치면 실패. 데려온 횟수 × 8원 + 성공 보너스 40원, 판다 우리가 있으면 2배. 끝나면 40초 쉬어야 합니다.
- 진행 상황은 브라우저 localStorage에 자동 저장됩니다(이전 버전 저장 데이터도 이어서 불러옴).
