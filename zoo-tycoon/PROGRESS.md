# 진행 상황 (이어서 작업하기용)

## 실행
- `zoo-tycoon` 폴더에서 `python3 -m http.server 8000` 실행 → 브라우저로 `http://localhost:8000` 접속.
  (`index.html`을 더블클릭해도 되지만, 그러면 브라우저 보안 때문에 배경음악 파일 대신 합성 음악이 나옵니다.)
- 저장 데이터는 브라우저 localStorage(`sunflower-zoo`)에 있습니다. 메뉴 → "처음부터 다시 하기"로 초기화.

## 파일
- `index.html`: 게임 전체(HTML/CSS/JS 한 파일)
- `assets/`: 게임용 그림 아틀라스·텍스처·`bgm.mp3`, `manifest.json`(그림 좌표)
- `art/`: 원본 그림 시트, 원본 음악
- `tools/slice_sprites.py`: 그림 시트 자르기 / `tools/loop_bgm.py`: 음악 루프 만들기
